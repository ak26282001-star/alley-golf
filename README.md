# Alley Golf

Website for Alley Golf: neon-lit crazy golf with a bar.

- `index.html`: the page (the hero alley scene is inline SVG)
- `assets/css/styles.css`: design system and layout
- `assets/js/main.js`: navigation, motion, course explorer, warm-up putting game, booking form
- `assets/js/config.js`: **booking endpoint, opening hours, prices, venue details (edit before launch)**

Static site, with no build step. See [DEPLOYMENT.md](DEPLOYMENT.md) for what's required before going live.
